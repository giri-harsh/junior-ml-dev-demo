A demo run on the home page uses a small public dataset under the time limits described below; it does not reproduce these benchmark numbers, which come from larger tasks and longer budgets. The source repository is currently private, so file references below (result JSONs, code) are names only, not links.

All 3 paired-difference intervals against FLAML and between the LLM and scripted planners include 0 (10 tasks, each arm run once): no difference between these arms is demonstrated.

A demo run has two limits: a 55 s soft wall after which the agent stops searching and wraps up (review, report), and a 90 s hard limit at which the whole process is killed (the AutoML ceiling is 20 s). Wrap-up and process start come on top of the soft wall, so a finished run can take longer than it.
