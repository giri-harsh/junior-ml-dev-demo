A junior ML engineer that shows its work and catches its own mistakes.

It profiles a tabular dataset, checks for leakage before modelling, trains and compares models against baselines, has a deterministic reviewer sign off, and writes a report. Deployment is gated by a single-use approval.

This is a static site, not a live demo. The example runs below were computed once with the project's scripted planner (no LLM) on a developer laptop (Windows 11), CPU only, and are shown as recorded. A live, interactive version runs separately on a free Render instance: https://junior-ml-dev-demo.onrender.com/ (it sleeps when idle, so the first visit can take about a minute; it is slower and lighter than the runs here: leakage detectors skipped, no FLAML). Hugging Face Docker and Gradio Spaces need a paid account. The source repository is currently private, so file references below (result JSONs, code) are names only, not links.

Example runs

Three small public OpenML tables, each run once with the same code and limits the repository's demo mode uses (scripted planner, FLAML 15 s). A demo run has two limits: a 55 s soft wall after which the agent stops searching and wraps up (review, report), and a 90 s hard limit at which the whole process is killed (the AutoML ceiling is 20 s). Wrap-up and process start come on top of the soft wall, so a finished run can take longer than it. Wall times are from one machine and will differ elsewhere. These are demo-scale tasks, not the benchmark.
